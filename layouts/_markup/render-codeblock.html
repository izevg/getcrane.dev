{{- /* Блок кода: подсветка Chroma с классами (цвета — токены --syn-*), шапка резервируется всегда, кнопку копирования добавляет остров. В блоках известных языков имена переменных окружения оборачиваются ссылками на справочник (ui-spec, «Переменные окружения env»): разбор идёт по максимальным «словам» [A-Za-z0-9_] уже подсвеченного HTML, поэтому MY_CRANE_TOKEN и CRANE_TOKENS не совпадают, а обёртка не добавляет ни одного символа текста и не меняет классы токенов Chroma. Неизвестное CRANE_* при params.envStrict ломает сборку. */ -}} {{- $p := .Page -}} {{- $lang := lower (.Type | default "text") -}} {{- /* У Chroma нет лексера dotenv: .env разбирается лексером bash (KEY=value, кавычки, $VAR, комментарии #). Метка языка остаётся исходной. */ -}} {{- $inner := "" -}} {{- if in (slice "dotenv" "env") $lang -}} {{- $inner = replaceRE `(?s)^.*?]*>(.*).*$` "$1" (transform.Highlight .Inner "bash" (dict "noClasses" false)) -}} {{- else -}} {{- $inner = (transform.HighlightCodeBlock .).Inner -}} {{- end -}} {{- $envLangs := slice "bash" "sh" "shell" "zsh" "console" "shell-session" "ini" "yaml" "yml" "toml" "env" "dotenv" "dockerfile" -}} {{- if in $envLangs $lang -}} {{- $url := partial "env/url.html" -}} {{- $out := slice -}} {{- range findRE `[A-Za-z0-9_]+|[^A-Za-z0-9_]+` $inner -}} {{- $w := . -}} {{- if or (hasPrefix $w "CRANE_") (hasPrefix $w "AWS_") -}} {{- $r := partial "env/lookup.html" $w -}} {{- if $r -}} {{- $id := partial "env/register.html" (dict "page" $p "r" $r) -}} {{- $frag := printf "%s%s" $r.anchor (cond $r.isFile "-file" "") -}} {{- $out = $out | append (printf `%s` $url $frag $id $w $w) -}} {{- else -}} {{- if and site.Params.envStrict (findRE `^CRANE_[A-Z0-9_]+$` $w) }}{{ errorf "env: неизвестное имя %s в блоке кода %q (%s); опечатка или его нет в data/env.yaml" $w $lang $p.Path }}{{ end -}} {{- $out = $out | append $w -}} {{- end -}} {{- else -}} {{- $out = $out | append $w -}} {{- end -}} {{- end -}} {{- $inner = delimit $out "" -}} {{- end -}} {{- /* Метка — человеческая подпись из каталога i18n, не id лексера. Атрибут file="…" показывает имя файла моноширинным; output="true" помечает вывод. */ -}} {{- $keys := dict "bash" "shell" "sh" "shell" "shell" "shell" "zsh" "shell" "console" "terminal" "shell-session" "terminal" "dotenv" "dotenv" "env" "dotenv" "yaml" "yaml" "yml" "yaml" "toml" "toml" "json" "json" "ini" "ini" "sql" "sql" "http" "http" "dockerfile" "dockerfile" "mermaid" "mermaid" "text" "text" "plaintext" "text" "output" "output" -}} {{- $isOutput := or (eq (.Attributes.output | default "" | string) "true") (in (slice "text" "plaintext" "output") $lang) -}} {{- $label := i18n (printf "code.lang.%s" (index $keys $lang | default "other")) -}} {{- if $isOutput }}{{ $label = i18n "code.lang.output" }}{{ end -}} {{- $isFile := false -}} {{- with .Attributes.file }}{{ $label = . }}{{ $isFile = true }}{{ end -}}
