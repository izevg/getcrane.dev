CRANE is an open, self-hosted package registry and proxy for public registries, covering Cargo, npm, PyPI, Maven and NuGet. The product protects the supply chain first and manages the registry second. The source code is distributed under the Apache-2.0 license.

This section collects facts about the project that do not belong to installation or configuration.
