CRANE отвечает на ошибку кодом HTTP и коротким телом с текстом на русском языке и идентификатором запроса. Форма тела зависит от маршрута: клиенты Cargo и npm получают тело в формате своего протокола, остальные маршруты и порт проб — `application/problem+json` ({{< cite "rfc-9457" >}}). Адреса хранилищ, пароли и внутренние причины в тело не попадают, они остаются в журнале ({{< xref "operations/logs" >}}).

Справочник перечисляет формы тела, поля `problem+json`, типы проблем, заголовки и значение каждого кода с текстом из сервера. Что делать с конкретной ошибкой, описано в {{< xref "operations/troubleshooting" >}}.

## Формы тела {#body-forms}

| Маршрут | `Content-Type` | Тело |
| --- | --- | --- |
| Cargo, `/cargo/<repo>/…` | `application/json` | `{"errors":[{"detail":"<текст> (request_id <id>)"}]}` |
| npm, `/npm/<repo>/…` | `application/json` | `{"error":"<текст> (request_id <id>)"}` |
| Остальные пути порта API, порт проб | `application/problem+json` | Объект `problem+json` |

Клиенты Cargo и npm показывают пользователю только текст ошибки, поэтому идентификатор запроса добавлен к тексту суффиксом `(request_id <id>)`.

## Поля problem+json {#problem-fields}

| Поле | Значение |
| --- | --- |
| `type` | Тип проблемы: `about:blank` или `urn:crane:problem:storage-unreachable` |
| `title` | Стандартная фраза статуса HTTP на английском языке: `Not Found`, `Service Unavailable` |
| `status` | Код ответа |
| `detail` | Текст на русском языке |
| `request_id` | Идентификатор запроса |

Других полей в теле нет.

## Типы проблем {#problem-types}

| `type` | Когда |
| --- | --- |
| `urn:crane:problem:storage-unreachable` | Каталог или хранилище blob не ответили: повтор позже имеет смысл. Всегда `503` |
| `about:blank` | Все остальные случаи, в том числе `503` «хранилище не готово»: смысл задаёт код ответа |

Для клиентов Cargo и npm тип не передаётся: у их форм тела нет поля `type`.

## Коды ответов {#statuses}

Колонка `detail` показывает фиксированный текст, а `<…>` — подставляемое значение.

### Запросы клиентов пакетов {#statuses-client}

| Код | `detail` | Когда |
| --- | --- | --- |
| `400` | текст причины | Недопустимое имя или версия, документ публикации не разобран, отказ по правилу формата (например, зависимость из стороннего реестра у Cargo) |
| `400` | `ошибка чтения тела запроса` | Тело запроса оборвано |
| `400` | ``крейт уже опубликован под именем `<имя>` `` | Cargo: публикация с другим написанием имени |
| `400` | `операция не поддерживается` | npm: `PUT` документа, который не публикация и не deprecate |
| `401` | `требуется токен` | В запросе нет заголовка с токеном; ответ несёт `WWW-Authenticate` формата |
| `403` | `токен отвергнут` | Токен неверный или предъявлен в чужой схеме; в аудит пишется отказ аутентификации |
| `403` | `версия недоступна: Quarantined` или `Blocked` | Версия в состоянии, при котором файл не отдаётся |
| `403` | `окно удаления закрыто: версия опубликована слишком давно` | Удаление версии после окна |
| `403` | `имя принадлежит namespace другого workspace` | Публикация имени, зарезервированного за другой командой |
| `403` | `имя занято в публичном реестре: для публикации нужна резервация платформы (CRANE_NAMESPACES)` | Новое имя уже есть в публичном реестре |
| `404` | `репозиторий не найден` | Репозиторий не создан: проверьте {{< env "CRANE_CARGO_REPOS" >}} и {{< env "CRANE_NPM_REPOS" >}} |
| `404` | `версия не найдена`, `файл версии не найден`, `тег не найден` | Нет версии, файла или тега |
| `404` | `не найдено` | Нет пакета или файла. Тот же ответ получает запрос к proxy за именем, которое CRANE считает внутренним, чтобы не раскрывать причину |
| `404` | `маршрут не найден` | Путь вне смонтированных маршрутов; тело `problem+json` |
| `405` | `репозиторий не hosted: публикация запрещена` | Запись в proxy-репозиторий |
| `409` | `версия уже существует`, `файл версии уже существует` | Повторная публикация. Номер версии занят навсегда, в том числе после удаления |
| `410` | `версия недоступна: Deleted` | Версия удалена |
| `413` | текст сервера | Тело публикации больше {{< env "CRANE_MAX_PUBLISH_BYTES" >}} |
| `422` | `контрольная сумма не совпала: заявлена <…>, получена <…>` | Дайджест, заявленный клиентом, не совпал с вычисленным |
| `422` | `формат требует scope в имени пакета` | Публикация npm-пакета без scope в hosted-репозиторий |
| `501` | `аудит уязвимостей через реестр не поддерживается` | npm: запрос `npm audit` |
| `501` | сообщение, что управление владельцами недоступно | Cargo: `PUT` или `DELETE` на `owners` |

### Отказы зависимостей {#statuses-dependency}

| Код | `detail` | Когда |
| --- | --- | --- |
| `500` | `внутренняя ошибка сервера` | Сбой хранилища, не связанный с недоступностью, или нарушенный инвариант. Причина в журнале: запись `внутренняя ошибка запроса` |
| `502` | `upstream недоступен` | Proxy: upstream не ответил, отказал, прислал документ, который нельзя разобрать, архив с неверной суммой или архив больше {{< env "CRANE_PROXY_MAX_ARTIFACT_BYTES" >}}; npm: у версии нет sha512 |
| `503` | `хранилище временно недоступно` | Каталог или хранилище blob не ответили: {{< term "fail-closed" >}}. Тип `urn:crane:problem:storage-unreachable` |
| `503` | `не удалось проверить имя в публичном upstream: повторите позже` | Публикация нового имени, когда публичный реестр недоступен |

### Порт проб {#statuses-probes}

| Код | `detail` | Когда |
| --- | --- | --- |
| `503` | `хранилище временно недоступно` | Проба готовности: хранилище не ответило или не уложилось в 1,5 с. Тип `urn:crane:problem:storage-unreachable` |
| `503` | `хранилище не готово` | Проба готовности: хранилище ответило ошибкой. Тип `about:blank` |
| `404` | `маршрут не найден` | Любой путь, кроме `/healthz/live` и `/healthz/ready`, в том числе `/metrics` |

## Заголовки ответа {#headers}

| Заголовок | Когда |
| --- | --- |
| `X-Request-Id` | В каждом ответе обоих портов. Это идентификатор запроса из тела ошибки и журнала; чужое значение сервер принимает только от доверенных прокси ({{< env "CRANE_TRUSTED_PROXIES" >}}) |
| `Retry-After: 10` | В каждом ответе `503`, независимо от формата |
| `WWW-Authenticate` | В ответе `401`: `Cargo` для Cargo и `Bearer realm="crane"` для npm |
| `Age`, `Warning` | В ответах proxy, обслуженных из кэша. `Warning: 110 - "Response is Stale"` — устаревшая копия, `Warning: 111 - "Revalidation Failed"` — копия отдана при отказе upstream |
