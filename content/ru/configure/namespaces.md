Страница описывает, как зарезервировать имена пакетов за платформой, чтобы CRANE никогда не отдавал их из публичного реестра. Резервирование задаёт переменная {{< env "CRANE_NAMESPACES" >}}: список записей `формат:шаблон`. Имя, которое покрывает {{< term "namespace" >}}, считается внутренним, и любой {{< term "proxy-repository" >}} отвечает на него `404`. Так закрывается {{< term "dependency-confusion" >}}. Почему защита устроена так и где её границы: {{< xref "features/security/namespace-reservation" >}}.

Сервер применяет список при старте, идемпотентно. Записи только добавляются: удаление записи из списка резервирование не снимает.

## Перед началом {#prerequisites}

- Список внутренних префиксов и имён по каждому формату.
- Запущенный сервер с постоянным каталогом: {{< xref "configure/storage" >}}.

## Шаги {#steps}

1. Составьте записи вида `формат:шаблон` через запятую. Формат пишется строчными буквами: `cargo`, `npm`, `pypi`, `maven` или `nuget`. Шаблон — точное имя или префикс с одной `*` в конце сразу после разделителя формата. Пробелы вокруг записей отбрасываются.

   | Формат | Запись | Что покрывает |
   | --- | --- | --- |
   | Cargo | `cargo:acme-*` | Имена с префиксом `acme-`; `-` и `_` в Cargo равнозначны |
   | PyPI | `pypi:acme-*` | Имена с префиксом `acme-` |
   | NuGet | `nuget:Acme.*` | Имена с префиксом `acme.`; регистр нормализуется |
   | Maven | `maven:com.acme.*` | groupId `com.acme` и вложенные группы |
   | Maven | `maven:com.acme:core` | Одно имя `groupId:artifactId`; формат отделяется по первому двоеточию |
   | npm | `npm:@acme/*` | Все пакеты scope `@acme`; префиксы без scope запрещены |

   Префикс `acme-*` не покрывает `acmecorp`: перед `*` обязателен разделитель формата.

2. При необходимости укажите владельца. Владелец — {{< term "workspace" "команда" >}}; её идентификатор записывается суффиксом `=<uuid>` после шаблона. Без суффикса владелец — команда по умолчанию `00000000-0000-0000-0000-000000000001`. Владелец отделяется по последнему знаку `=`.

3. Задайте переменную.

   ```ini
   CRANE_NAMESPACES=cargo:acme-*,cargo:acme-payments-*=<uuid>,npm:@acme/*
   ```

   В файле TOML ключ называется `namespaces`; допустима строка или массив строк:

   ```toml
   namespaces = ["cargo:acme-*", "npm:@acme/*"]
   ```

4. Перезапустите сервер.

Каждую запись, применённую при старте, сервер записывает в журнал аудита от имени `crane:config`. Шаблон, который уже принадлежит другой команде, останавливает старт: владение через конфигурацию не передаётся.

## Проверка {#verify}

Проверьте действие резервирования на отдельном тестовом стенде, где каталог и blob лежат в памяти (`memory`). Резервирование записывается в каталог, а в постоянном каталоге остаётся навсегда. Зарезервируйте имя, которое точно есть в crates.io, и запросите его через proxy-репозиторий Cargo.

```dotenv
CRANE_NAMESPACES=cargo:serde
CRANE_CARGO_PROXY_REPOS=crates-io
```

```bash
printf 'header = "Authorization: %s"\n' "$(cat ./secrets/crane_token)" \
  | curl -sS -o /dev/null -w '%{http_code}\n' -K - \
    https://crane.example.com/cargo/crates-io/index/se/rd/serde
```

```text
404
```

Без записи в {{< env "CRANE_NAMESPACES" >}} тот же запрос возвращает документ индекса.

## Ошибки запуска {#errors}

Сообщения называют переменную и причину, но не процитированное значение целиком. Тексты на русском языке. Примеры идут по порядку: пустая запись, нет формата, неизвестный формат, некорректный шаблон, некорректный uuid, повтор шаблона после нормализации, чужой владелец.

```text
некорректное значение CRANE_NAMESPACES: пустая запись в списке
некорректное значение CRANE_NAMESPACES: ожидается `формат:шаблон`
некорректное значение CRANE_NAMESPACES: неизвестный формат
некорректное значение CRANE_NAMESPACES: некорректный шаблон
некорректное значение CRANE_NAMESPACES: некорректный uuid workspace
некорректное значение CRANE_NAMESPACES: шаблон повторяется в списке
namespace acme_* уже принадлежит другому workspace; владение не передаётся через конфигурацию
```
