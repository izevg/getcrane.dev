{{- /* {{< screenshot story="S3Versions" variant="Desktop1440Sheet" alt="…" >}} Файлы: static/screens//.{avif,webp}. Светлый вариант указывает статья; тёмный и английский берутся из data/screen-pairs.yaml. Размеры — ui/screen-dims.html. Тема выбирается по data-theme, без JS — по prefers-color-scheme (CSS .window .shot-light/.shot-dark). Подпись заканчивается пометкой «Демонстрационные данные» / «Demo data».
