CRANE требует PostgreSQL 17 или новее с расширениями `vector` (pgvector 0.8 и выше) и `pg_trgm`. Команда `crane migrate` создаёт недостающие расширения сама, если у роли хватает прав, и до этого не применяет миграции. Страница собирает версии, образы, ресурсы и инструменты, на которых проверено развёртывание.

## PostgreSQL {#postgresql}

| Компонент | Требование |
| --- | --- |
| PostgreSQL | 17 и новее |
| `vector` (pgvector) | 0.8 и новее |
| `pg_trgm` | любая версия; версия не проверяется |

Каталог хранится только в PostgreSQL. Адрес подключения задаёт {{< env "CRANE_DATABASE_URL" >}} или {{< env "CRANE_DATABASE_URL_FILE" >}}: схема `postgres://` или `postgresql://`. Значение `memory` включает каталог в памяти, данные при этом теряются при перезапуске; такой каталог нельзя сочетать с постоянным {{< env "CRANE_BLOBS" >}}.

## Расширения и `crane migrate` {#extensions}

Перед миграциями `crane migrate` проверяет каждое расширение и ведёт себя по таблице. Параллельные запуски сериализуются блокировками, поэтому две миграции не работают одновременно.

| Состояние базы | Что делает `crane migrate` |
| --- | --- |
| Расширение установлено, версия не ниже требуемой | Ничего не меняет, применяет миграции |
| Расширения нет, пакет доступен на сервере, у роли хватает прав | Выполняет `CREATE EXTENSION IF NOT EXISTS`, затем применяет миграции |
| Расширения нет, пакета нет на сервере или его версия ниже требуемой | Завершается с ошибкой, в которой названо расширение; миграции не применяются |
| Расширения нет, у роли не хватает прав (SQLSTATE `42501`) | Завершается с ошибкой и готовым SQL для администратора базы; миграции не применяются |
| `vector` установлен, но старше 0.8 | Завершается с ошибкой с подсказкой `ALTER EXTENSION vector UPDATE;`; миграции не применяются |

Тексты ошибок выводятся на русском языке:

```text
расширение PostgreSQL vector недоступно на сервере (или версия пакета ниже требуемой): установите пакет с ним (pgvector >= 0.8 для vector, contrib для pg_trgm)
расширения PostgreSQL pg_trgm нет, а роли не хватает прав его создать: администратор БД выполняет в базе каталога `CREATE EXTENSION pg_trgm;`
расширение PostgreSQL vector версии 0.7.4 старше требуемой 0.8: администратор БД выполняет в базе каталога `ALTER EXTENSION vector UPDATE;`
```

Права на создание различаются. Расширение `vector` недоверенное: создать его может только суперпользователь. Расширение `pg_trgm` доверенное: достаточно права `CREATE` на базе. В управляемом PostgreSQL администратор базы заранее выполняет в базе каталога:

```sql
CREATE EXTENSION vector;
CREATE EXTENSION pg_trgm;
```

С уже созданными расширениями `crane migrate` работает под ролью без этих прав.

## Образы {#images}

Образы закреплены в `.env.dist` в формате `тег@sha256:<digest индекса>`. Тег нужен человеку, образ выбирает {{< term "digest" >}} мультиархитектурного индекса.

| Переменная | Значение (тег) | Назначение |
| --- | --- | --- |
| {{< env "CRANE_IMAGE" >}} | `crane/crane` | Образ CRANE; собирается локально, в реестр не публикуется |
| {{< env "CRANE_VERSION" >}} | `latest` | Тег образа CRANE; версия не закреплена |
| {{< env "CADDY_IMAGE" >}} | `caddy:2.11.7` | Обратный прокси и TLS |
| {{< env "POSTGRES_IMAGE" >}} | `pgvector/pgvector:0.8.7-pg17-bookworm` | PostgreSQL 17.11 с pgvector 0.8.7 |
| {{< env "VALKEY_IMAGE" >}} | `valkey/valkey:8.1.11` | Кэш, {{< xref "deploy/valkey-cache" "режим Valkey" >}} |
| `SEAWEEDFS_IMAGE` | `chrislusf/seaweedfs:4.51` | S3-хранилище, {{< xref "deploy/s3-storage" "режим S3" >}} |

Точные дайджесты записаны в `.env.dist`. Чтобы обновить образ, возьмите строку `Digest` верхнего уровня из вывода команды:

```bash
docker buildx imagetools inspect <образ:тег>
```

## Ресурсы по умолчанию {#resources}

| Параметр | Значение по умолчанию | Где действует |
| --- | --- | --- |
| {{< env "CRANE_CPUS" >}} | `2` | Предел CPU сервиса `crane` в Compose |
| {{< env "CRANE_MEMORY" >}} | `1g` | Предел памяти сервиса `crane` в Compose |
| {{< env "VALKEY_MAXMEMORY" >}} | `512mb` | Предел памяти Valkey в режиме Valkey; политика вытеснения `allkeys-lru` зафиксирована в compose-файле |

Кэш `memory` ограничен 256 МиБ веса записей (тела документов proxy). Предел задан в коде и не настраивается переменной.

| Инструмент | Для чего | Примечание |
| --- | --- | --- |

| go-task и Node.js 24 | Задача `task secrets:init` | Версия Node.js записана в `.nvmrc` |
