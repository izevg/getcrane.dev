Справочник перечисляет все переменные окружения, которые читает бинарник `crane`: назначение, значение по умолчанию, обязательность, наличие формы `<ИМЯ>_FILE` и ключ файла TOML. Переменные группируются по назначению. Как задать их пошагово: {{< xref "configure" >}}.

Сервер читает настройки один раз при старте. Четыре переменные обязательны: {{< env "CRANE_DATABASE_URL" >}}, {{< env "CRANE_BLOBS" >}}, {{< env "CRANE_PUBLIC_URL" >}} и {{< env "CRANE_TOKEN" >}}. Остальные имеют значения по умолчанию или необязательны.

## Порядок источников {#precedence}

Значение берётся из первого источника, который его задал:

1. переменная окружения; заданная пустой строкой, она тоже считается заданной и перекрывает файл;
2. ключ файла TOML, путь к которому задаёт {{< env "CRANE_CONFIG" >}};
3. строка таблицы `setting` в PostgreSQL (кроме ключей `http_port`, `admin_port`, `trusted_proxies`, `database_url`, `settings_key`);
4. значение по умолчанию.

Порядок считается по имени переменной. Сервер сообщает о первой найденной ошибке и завершается с кодом `1`.

## Ключи файла TOML {#toml}

- Ключ — имя переменной без префикса `CRANE_` в нижнем регистре: {{< env "CRANE_HTTP_PORT" >}} — `http_port`. Для формы `_FILE` ключ имеет суффикс `_file`: `token_file`.
- Допустимые значения: строка, целое число, массив строк. Массив сервер склеивает запятыми. Другие типы дают ошибку ``некорректное значение ключа `<ключ>` в файле конфигурации: <причина>``.
- Неизвестный ключ, в том числе `config`, даёт ошибку ``неизвестный ключ `<ключ>` в файле конфигурации``.
- Переменные `AWS_*` и их формы `_FILE`, {{< env "CRANE_CONFIG" >}} и {{< env "RUST_LOG" >}} не имеют ключей TOML: их задаёт только окружение.
- Ошибка чтения файла называет путь и причину ввода-вывода. Ошибка разбора называет путь, строку и столбец, но не цитирует содержимое.
- Пустое значение {{< env "CRANE_CONFIG" >}} означает «файла нет».

## Формы _FILE {#file-forms}

- Значение формы `_FILE` — путь к файлу. Сервер убирает из конца содержимого символы `\r` и `\n`; остальные пробелы сохраняются.
- Переменная и её форма `_FILE` вместе дают ошибку `переменные <ИМЯ> и <ИМЯ>_FILE взаимоисключающие`. Это верно и для значений из разных источников: ключ `token` файла TOML и {{< env "CRANE_TOKEN_FILE" >}} в окружении тоже конфликтуют.
- Пустое значение или пустой файл даёт ошибку `некорректное значение <ИМЯ>: значение пусто`.
- Файл, который не читается, даёт ошибку `не удалось прочитать <ИМЯ>_FILE: <причина>`.
- Значения секретов в тексты ошибок не попадают. Для чужой схемы URL называется только схема.

## memory и постоянное хранилище {#memory}

- Значение `memory` для {{< env "CRANE_DATABASE_URL" >}} и {{< env "CRANE_BLOBS" >}} пишется явно.
- `memory` нельзя смешивать с постоянным хранилищем: пара либо вся в памяти, либо вся постоянная. Иначе сервер не стартует с ошибкой `CRANE_DATABASE_URL и CRANE_BLOBS: memory нельзя смешивать с постоянным хранилищем`.
- При каталоге `memory` ключ {{< env "CRANE_SETTINGS_KEY" >}} даёт ошибку «не нужен при memory». Ключи S3 из файлов (`AWS_*_FILE`) дают такую же ошибку, когда blob — `memory`.
- {{< env "CRANE_CACHE" >}} со значением `memory` с постоянным хранилищем сочетается: кэш не источник истины.

## Переменные {#variables}

В колонке «Из файла» указана форма `_FILE`, если она есть. В колонке «По умолчанию» для секретных переменных значение не показывается; поведение без значения описано в назначении.

### Файл настроек {#group-config}

| Имя | Назначение | По умолчанию | Обязательна | Из файла | Ключ TOML |
| --- | --- | --- | --- | --- | --- |
| {{< env "CRANE_CONFIG" >}} | Путь к необязательному файлу TOML. Пустое значение — файла нет | нет | Нет | Нет | только окружение |

### Сеть {#group-network}

| Имя | Назначение | По умолчанию | Обязательна | Из файла | Ключ TOML |
| --- | --- | --- | --- | --- | --- |
| {{< env "CRANE_HTTP_PORT" >}} | Порт API с протоколами пакетов; целое число 0–65535 | `8080` | Нет | Нет | `http_port` |
| {{< env "CRANE_ADMIN_PORT" >}} | Порт проб `/healthz/live` и `/healthz/ready`; его читает и `crane healthcheck` | `9464` | Нет | Нет | `admin_port` |
| {{< env "CRANE_PUBLIC_URL" >}} | Внешний адрес: `http://` или `https://` и хост; завершающие `/` отбрасываются | нет | Да | Нет | `public_url` |
| {{< env "CRANE_TRUSTED_PROXIES" >}} | IP-адреса и сети CIDR (IPv4, IPv6) через запятую, чьим `X-Forwarded-For` и `X-Request-Id` верит сервер | пустая строка | Нет | Нет | `trusted_proxies` |

### Доступ {#group-access}

| Имя | Назначение | По умолчанию | Обязательна | Из файла | Ключ TOML |
| --- | --- | --- | --- | --- | --- |
| {{< env "CRANE_TOKEN" >}} | Статический токен доступа к протоколам; задаётся значением или файлом, ровно одним способом | нет | Да | Да, {{< env "CRANE_TOKEN_FILE" >}} | `token`, `token_file` |
| {{< env "CRANE_TOKEN_PRINCIPAL" >}} | Имя принципала токена: непустое, без управляющих символов; пробелы по краям отбрасываются | `crane` | Нет | Нет | `token_principal` |

### Хранилища {#group-storage}

| Имя | Назначение | По умолчанию | Обязательна | Из файла | Ключ TOML |
| --- | --- | --- | --- | --- | --- |
| {{< env "CRANE_DATABASE_URL" >}} | Каталог: `memory`, `postgres://` или `postgresql://` | нет | Да | Да, {{< env "CRANE_DATABASE_URL_FILE" >}} | `database_url`, `database_url_file` |
| {{< env "CRANE_BLOBS" >}} | Blob: `memory`, `file:///абсолютный/путь` или `s3://бакет[/префикс]` с несекретными параметрами запроса | нет | Да | Нет | `blobs` |
| {{< env "AWS_ACCESS_KEY_ID" >}} | Идентификатор статического ключа S3. Значение читает клиент S3; форму `_FILE` читает сервер, парой с секретной частью | нет | Нет | Да, {{< env "AWS_ACCESS_KEY_ID_FILE" >}} | только окружение |
| {{< env "AWS_SECRET_ACCESS_KEY" >}} | Секретная часть статического ключа S3 | нет | Нет | Да, {{< env "AWS_SECRET_ACCESS_KEY_FILE" >}} | только окружение |
| {{< env "CRANE_SETTINGS_KEY" >}} | Ключ шифрования секретов настроек в PostgreSQL: base64 от ровно 32 байт (AES-256-GCM). При каталоге `memory` — ошибка | нет | Нет | Да, {{< env "CRANE_SETTINGS_KEY_FILE" >}} | `settings_key`, `settings_key_file` |

### Кэш и пределы {#group-limits}

| Имя | Назначение | По умолчанию | Обязательна | Из файла | Ключ TOML |
| --- | --- | --- | --- | --- | --- |

| {{< env "CRANE_MAX_PUBLISH_BYTES" >}} | Предел тела публикации для Cargo и npm, байты; больше нуля | `10485760` | Нет | Нет | `max_publish_bytes` |

### Репозитории и namespace {#group-repositories}

| Имя | Назначение | По умолчанию | Обязательна | Из файла | Ключ TOML |
| --- | --- | --- | --- | --- | --- |
| {{< env "CRANE_CARGO_REPOS" >}} | Имена hosted-репозиториев Cargo через запятую; пустое значение — ошибка | `internal` | Нет | Нет | `cargo_repos` |
| {{< env "CRANE_CARGO_PROXY_REPOS" >}} | Имена proxy-репозиториев crates.io через запятую; пусто — proxy Cargo выключен | пустая строка | Нет | Нет | `cargo_proxy_repos` |
| {{< env "CRANE_NPM_REPOS" >}} | Имена hosted-репозиториев npm через запятую; пусто — репозиториев нет | пустая строка | Нет | Нет | `npm_repos` |
| {{< env "CRANE_NPM_PROXY_REPOS" >}} | Имена proxy-репозиториев registry.npmjs.org через запятую; пусто — proxy npm выключен | пустая строка | Нет | Нет | `npm_proxy_repos` |
| {{< env "CRANE_NAMESPACES" >}} | Резервирование имён: записи `формат:шаблон` или `формат:шаблон=uuid` через запятую | пустая строка | Нет | Нет | `namespaces` |

Правила имён репозиториев: буквы ASCII, цифры, `-`, `_`, `.`; без пустых имён и повторов; proxy-репозиторий не повторяет имя hosted-репозитория того же формата.
