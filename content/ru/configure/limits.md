Страница описывает два предела размера. {{< env "CRANE_MAX_PUBLISH_BYTES" >}} ограничивает тело запроса публикации в hosted-репозитории. {{< env "CRANE_PROXY_MAX_ARTIFACT_BYTES" >}} ограничивает размер одного артефакта, который {{< term "proxy-repository" "proxy-репозиторий" >}} скачивает из {{< term "upstream" >}}. Оба предела задаются целым числом байт.

Других настраиваемых пределов размера у сервера нет. Остальные пределы движка proxy имеют фиксированные значения.

## Перед началом {#prerequisites}

- Размер самых больших пакетов, которые публикуют команды, и самых больших артефактов, которые они устанавливают.

## Шаги {#steps}

1. Задайте предел публикации. Значение по умолчанию — `10485760` (10 МиБ). Предел действует для Cargo и npm. Тело публикации буферизуется в памяти целиком, поэтому большой предел увеличивает расход памяти. У npm tarball приходит в base64 внутри JSON, то есть примерно на треть больше исходного файла: предел применяется к документу целиком, и при значении по умолчанию допустим пакет примерно до 7,5 МиБ.

   ```ini
   CRANE_MAX_PUBLISH_BYTES=20971520
   ```

2. Задайте предел проксируемого артефакта. Значение по умолчанию — `2147483648` (2 ГиБ).

   ```ini
   CRANE_PROXY_MAX_ARTIFACT_BYTES=1073741824
   ```

3. Перезапустите сервер.

Оба значения — десятичные целые числа без единиц измерения (`20971520`, а не `20MB`) и строго больше нуля. В файле TOML ключи называются `max_publish_bytes` и `proxy_max_artifact_bytes`; значение — целое число или строка:

```toml
max_publish_bytes = 20971520
proxy_max_artifact_bytes = 1073741824
```

## Проверка {#verify}

Публикация, тело которой больше предела, получает ответ `413`. Артефакт больше предела при запросе через proxy получает ответ `502`. Сервер стартует без ошибки, если значения допустимы.

## Ошибки запуска {#errors}

Тексты на русском языке. Примеры идут по порядку: не число, ноль.

```text
некорректное значение CRANE_MAX_PUBLISH_BYTES: ожидалось целое число в допустимом диапазоне
некорректное значение CRANE_PROXY_MAX_ARTIFACT_BYTES: предел должен быть больше нуля
```
