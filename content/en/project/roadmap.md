This page shows which CRANE features arrive in which versions and groups them by topic: security, formats, console, operations, access and integrations. The plan may change and is not a commitment: the content of versions is refined as development goes on, and the page contains no dates.

Every feature has a status: "Released", "In development" or "Planned for X.Y". Released versions are collapsed, and the description of their capabilities matches the release. The {{< xref "versions" >}} page opens the documentation of released versions.
