{{- /* Блок кода: подсветка Chroma с классами (цвета — токены --syn-*), шапка резервируется всегда, кнопку копирования добавляет остров. В блоках известных языков имена переменных окружения оборачиваются ссылками на справочник (ui-spec, «Переменные окружения env»): разбор идёт по максимальным «словам» [A-Za-z0-9_] уже подсвеченного HTML, поэтому MY_CRANE_TOKEN и CRANE_TOKENS не совпадают, а обёртка не добавляет ни одного символа текста и не меняет классы токенов Chroma. Неизвестное CRANE_* при params.envStrict ломает сборку. */ -}} {{- $p := .Page -}} {{- $lang := lower (.Type | default "text") -}} {{- $hl := transform.HighlightCodeBlock . -}} {{- $inner := $hl.Inner -}} {{- $envLangs := slice "bash" "sh" "shell" "zsh" "console" "shell-session" "ini" "yaml" "yml" "toml" "env" "dotenv" "dockerfile" -}} {{- if in $envLangs $lang -}} {{- $url := partial "env/url.html" -}} {{- $out := slice -}} {{- range findRE `[A-Za-z0-9_]+|[^A-Za-z0-9_]+` $inner -}} {{- $w := . -}} {{- if or (hasPrefix $w "CRANE_") (hasPrefix $w "AWS_") -}} {{- $r := partial "env/lookup.html" $w -}} {{- if $r -}} {{- $id := partial "env/register.html" (dict "page" $p "r" $r) -}} {{- $frag := printf "%s%s" $r.anchor (cond $r.isFile "-file" "") -}} {{- $out = $out | append (printf `%s` $url $frag $id $w $w) -}} {{- else -}} {{- if and site.Params.envStrict (findRE `^CRANE_[A-Z0-9_]+$` $w) }}{{ errorf "env: неизвестное имя %s в блоке кода %q (%s); опечатка или его нет в data/env.yaml" $w $lang $p.Path }}{{ end -}} {{- $out = $out | append $w -}} {{- end -}} {{- else -}} {{- $out = $out | append $w -}} {{- end -}} {{- end -}} {{- $inner = delimit $out "" -}} {{- end -}} {{- $label := $lang -}} {{- with .Attributes.file }}{{ $label = . }}{{ end -}}
